## 每门课的难度等级

| 等级 | 说明 |
|------|------|
| **L2 物理理解** | 概念清晰，会画物理图像 |
| **L3 数学描述** | 公式推导，关键步骤懂 |
| **L4 深入理论** | 公式要会推导，能做习题 |
| **L5 前沿延伸** | 理解到能读论文程度 |

## 快速通道

| 背景 | 推荐路径 |
|------|----------|
| 有物理背景 | 固体物理 → 凝聚态物理 → 拓扑光学 → 超表面 |
| 有光学背景 | 量子光学 → 激光物理 → 半导体物理 → 超材料 |
| 有EE背景 | 固体物理 → 半导体物理 → 微波工程 → 超表面 |
| THz方向 | 激光物理 → 固体物理 → 超表面 → 拓扑光学 |
